# Rubric summary (stakeholder-facing)

## Do not compete on

Raw skill folder count. NVIDIA’s catalog (~hundreds) is inflated by API, model, and install-variant shards (e.g. DOCA, TAO, Jetson BSP).

## Compete on (headline five)

1. **Jobs covered** — shared taxonomy denominator  
2. **E2E jobs** — path to a verified artifact  
3. **Median depth** — words + deferred refs/scripts  
4. **Skills per job** — target band 1–3; ≫3 = over-split smell  
5. **Entry / routing** — orchestrator for non-experts (progressive disclosure)

## Optional sixth

Governance: evals, security scan, skill cards / signatures.

## Closing bakeoff metric

Task success rate on shared jobs (same agent harness), plus turns and human interventions — not folder count.
