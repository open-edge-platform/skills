# Rubric summary (stakeholder-facing)

## Do not compete on

Raw skill folder count.

- **NVIDIA** (~hundreds): API, model, and install-variant shards (DOCA, TAO, Jetson BSP).
- **AMD** (dozens, growing): LLM/ROCm focus — different surface than Edge CV; do not equate folder count with Edge AI coverage.
- **Qualcomm** (early): board/devkit shards for one Ethernet job — classic over-split.

## Compete on (headline five)

1. **Jobs covered** — shared taxonomy denominator (includes competitor-only rows so gaps stay honest)  
2. **E2E jobs** — path to a verified artifact  
3. **Median depth** — words + deferred refs/scripts  
4. **Skills per job** — target band 1–3; ≫3 = over-split smell  
5. **Entry / routing** — orchestrator for non-experts (progressive disclosure)

## Optional sixth

Governance: evals, security scan, skill cards / signatures (NVIDIA and AMD market this).

## Closing bakeoff metric

Task success rate on shared jobs (same agent harness), plus turns and human interventions — not folder count. Bake off NVIDIA where products overlap; treat AMD LLM and Qualcomm Linux as adjacent markets unless scope expands.
